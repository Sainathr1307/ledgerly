# Ledgerly data layer — API reference

Signatures are copied from the real code in `App/Data`, `App/Services` and `App/AppRouter.swift`. None of this has been compiled (no Xcode on the authoring machine). This file is excluded from the app target.

All record types (`TransactionRecord`, `CategoryRecord`, `MerchantRule`, `WeeklyEarning`, `MonthKey`, `MonthlyGoal`, `PaymentMethod`, `SourceKind`) come from `import LedgerlyCore`.

## Notification.Name.ledgerDidChange

```swift
extension Notification.Name { static let ledgerDidChange: Notification.Name }
```

Posted on the **main thread**, `object: nil`, shortly after every successful repository write (it is hopped to the main actor in a `Task`, so it arrives just after the write call returns, not before). Writes from the background App Intent post it too, because the intent uses the same `LedgerRepository.shared`. One notification per call, including the bulk calls.

Typical view-model use:

```swift
// in an @MainActor @Observable view model
func start() {
    observer = Task { [weak self] in
        for await _ in NotificationCenter.default.notifications(named: .ledgerDidChange) {
            await self?.reload()
        }
    }
}
func reload() async { data = await LedgerRepository.shared.snapshotAll() }
```

## LedgerData

```swift
struct LedgerData: Sendable, Equatable {
    var transactions: [TransactionRecord] = []   // newest first
    var categories: [CategoryRecord] = []        // by sortOrder, INCLUDES archived
    var rules: [MerchantRule] = []               // by normalizedMerchant
    var earnings: [WeeklyEarning] = []           // oldest week first
    var goals: [MonthlyGoal] = []                // oldest month first
    static let empty: LedgerData
}
```

Memberwise init is available with every argument optional: `LedgerData(transactions:categories:rules:earnings:goals:)`.

## LedgerRepository

```swift
@ModelActor actor LedgerRepository {
    static let shared: LedgerRepository          // over SharedModelContainer.shared
    init(modelContainer: ModelContainer)         // generated by @ModelActor; for tests/previews
}
```

It is an actor: **every call needs `await`**. Reads don't throw (a failed fetch returns empty/nil). **Writes throw** (`try await`); on a failed save the pending change is rolled back and no notification is posted.

```swift
// Transactions
func allTransactions() -> [TransactionRecord]                      // newest first
func transactions(in interval: DateInterval?) -> [TransactionRecord] // start <= date < end (END EXCLUSIVE); nil = all; newest first
func transaction(id: UUID) -> TransactionRecord?
func upsert(_ record: TransactionRecord) throws                    // updates in place when the id exists
func upsertTransactions(_ records: [TransactionRecord]) throws     // one save, one notification
func deleteTransaction(id: UUID) throws                            // no-op if missing
func knownMerchants() -> [String]                                  // distinct, most frequent first, then most recent

// Categories
func categories(includeArchived: Bool) -> [CategoryRecord]         // by sortOrder
func upsert(_ record: CategoryRecord) throws
func reorderCategories(_ orderedIDs: [UUID]) throws                // listed ids get sortOrder 0,1,2…; the rest follow in their old order
func seedDefaultCategoriesIfNeeded() throws                        // inserts DefaultCategories.all only when there are zero categories

// Merchant rules
func rules() -> [MerchantRule]
func setRule(merchant: String, categoryID: UUID) throws            // pass the RAW merchant; it is normalized here. No-op if it normalizes to ""
func deleteRule(normalizedMerchant: String) throws                 // pass MerchantRule.normalizedMerchant

// Weekly earnings
func earnings() -> [WeeklyEarning]                                 // oldest first
func setEarning(weekStart: Date, amount: Decimal) throws           // any date in the week; snapped to Monday 00:00, current time zone
func deleteEarning(weekStart: Date) throws                         // same snapping; no-op if missing

// Monthly goals
func goal(for month: MonthKey) -> MonthlyGoal?                     // exactly that month
func latestGoal(before month: MonthKey) -> MonthlyGoal?            // most recent month strictly before
func setGoal(_ amount: Decimal, for month: MonthKey) throws

// Bulk
func snapshotAll() -> LedgerData                                   // everything, one call
func importData(_ data: LedgerData) throws                         // upserts everything in `data`, one save, one notification; rows not mentioned are kept
func eraseAll() throws                                             // deletes all five entity types, then re-inserts DefaultCategories.all
```

Call examples:

```swift
let data = await LedgerRepository.shared.snapshotAll()
try await LedgerRepository.shared.upsert(record)                  // TransactionRecord or CategoryRecord — overloaded on the argument type
try await LedgerRepository.shared.setGoal(Decimal(200), for: MonthKey(date: now, calendar: .current))
```

Notes:
- The app must call `try? await LedgerRepository.shared.seedDefaultCategoriesIfNeeded()` at launch (and the intent should too, before categorizing, in case it runs before the app has ever been opened).
- `importData` stores rule merchants and earning week starts exactly as given (no normalizing/snapping) — the demo seeder should pass Core-generated values.
- `eraseAll()` does not touch `AppSettings`; call `AppSettings.shared.resetAll()` as well if settings should reset.
- `upsert` on two overloads: if type inference ever complains, annotate the argument's type.

## SharedModelContainer

```swift
enum SharedModelContainer {
    static let shared: ModelContainer      // on disk; in memory under -uiTesting or after a store failure
    static let startupError: String?       // non-nil = on-disk store failed, running on temporary in-memory storage; show it to the user
    static let isInMemory: Bool
}
enum LedgerSchema {
    static var models: [any PersistentModel.Type] { get }
    static var schema: Schema { get }
}
```

View models should go through `LedgerRepository`, not `@Query`. There is no need to attach `.modelContainer(...)` to the scene.

## AppSettings and LaunchFlags

```swift
@MainActor @Observable final class AppSettings {
    static let shared: AppSettings                 // init is private
    var hasCompletedOnboarding: Bool               // default false (forced true under -uiTesting)
    var lastGoalPromptMonth: String?               // "yyyy-MM" (== MonthKey.stringValue), nil if never prompted
    var reminderHour: Int                          // default 8, clamped 0…23
    var reminderMinute: Int                        // default 0, clamped 0…59
    var faceIDLockEnabled: Bool                    // default false
    var financeKitEnabled: Bool                    // default false
    var currencyCode: String                       // default "USD"
    var demoDataLoaded: Bool                       // default false
    func resetAll()                                // everything back to defaults
    nonisolated static var storedCurrencyCode: String { get }   // same value as currencyCode, readable off the main actor (for the App Intent)
}

enum LaunchFlags {
    static let uiTestingDefaultsSuite: String      // "uitests"
    static var isUITesting: Bool { get }           // "-uiTesting"
    static var forceGoalPrompt: Bool { get }       // "-uiTestingGoalPrompt"
    static var seedReviewItem: Bool { get }        // "-uiTestingSeedReview"
}
```

Under `-uiTesting`, settings live in the `"uitests"` UserDefaults suite, which is wiped at every launch, and `hasCompletedOnboarding` starts `true`. **Not handled here** (the app layer must do these, using `LaunchFlags`): suppressing the automatic monthly goal sheet unless `forceGoalPrompt`, skipping demo data, and inserting the review item for `seedReviewItem`.

Properties are observable: a SwiftUI view that reads `AppSettings.shared.currencyCode` re-renders when it changes. For bindings use `@Bindable var settings = AppSettings.shared`.

## AppRouter

```swift
enum AppTab: String, Hashable, Sendable, CaseIterable { case home, transactions, insights, settings }

@MainActor @Observable final class AppRouter {
    enum Destination: String, Hashable, Sendable { case earnings, review, transactions }
    static let shared: AppRouter
    var pendingDestination: Destination?   // set by a notification tap; the root view presents it, then sets it to nil
    var selectedTab: AppTab                // default .home
    var isAddSheetPresented: Bool          // default false
    init()
    func open(_ destination: Destination)  // closes the add sheet, selects the tab (.transactions → Transactions tab, others → Home), sets pendingDestination
}
```

The root view should watch `pendingDestination` with `.onChange(of:initial:)` using `initial: true`, so a tap that launched the app cold is also handled.

## NotificationService and NotificationDelegate

```swift
enum NotificationService {
    static let weeklyEarningsReminderIdentifier: String   // "ledgerly.weeklyEarningsReminder"
    static let destinationKey: String                     // "destination"

    static func requestAuthorization() async -> Bool      // false on denial/error; returns false WITHOUT prompting under -uiTesting
    static func authorizationStatus() async -> UNAuthorizationStatus
    static func isAuthorized() async -> Bool              // authorized, provisional or ephemeral

    @discardableResult
    static func scheduleWeeklyEarningsReminder(hour: Int, minute: Int) async -> Bool   // every Monday, local time; replaces the previous one; false + no-op without permission
    static func cancelWeeklyEarningsReminder()            // synchronous
    static func pendingReminderDescription() async -> String?   // e.g. "Every Monday at 8:00 AM"; nil if none scheduled

    @discardableResult
    static func postTransactionLogged(title: String, body: String, needsReview: Bool) async -> Bool   // immediate; userInfo destination "review" or "transactions"; false + no-op without permission
}

final class NotificationDelegate: NSObject, UNUserNotificationCenterDelegate, Sendable {
    static let shared: NotificationDelegate
    static func install()                                 // call once in the App's init
}
```

All functions are nonisolated and safe to call from any actor (including the intent's `perform()`). Files that mention `UNAuthorizationStatus` need `import UserNotifications`.

Expected wiring (app layer):
- `LedgerlyApp.init`: `NotificationDelegate.install()`.
- After onboarding grants permission, and whenever the reminder time changes in Settings: `await NotificationService.scheduleWeeklyEarningsReminder(hour: settings.reminderHour, minute: settings.reminderMinute)`.
- The reminder's userInfo is `["destination": "earnings"]`; a tap ends up as `AppRouter.shared.pendingDestination == .earnings`.
- With permission denied everything returns false / nil and nothing crashes; the in-app earnings card is the fallback.

## AppLockService and LockScreenView

```swift
@MainActor @Observable final class AppLockService {
    static let shared: AppLockService
    private(set) var isLocked: Bool              // starts true when faceIDLockEnabled (never under -uiTesting)
    private(set) var isAuthenticating: Bool
    private(set) var lastErrorMessage: String?
    init()
    static func canAuthenticate() -> Bool        // device has Face ID / Touch ID / passcode
    func lockIfEnabled()                         // call when scenePhase becomes .background
    func unlock() async                          // system prompt (.deviceOwnerAuthentication: biometrics with passcode fallback)
}

struct LockScreenView: View {
    let lock: AppLockService                     // LockScreenView(lock: AppLockService.shared)
}
```

Expected wiring: overlay `LockScreenView(lock: lock)` on the root content when `lock.isLocked`; call `lock.lockIfEnabled()` on `.background` (not `.inactive`, which also fires while the Face ID prompt is up). The view prompts by itself when it appears. If the device has no passcode at all, `unlock()` lets the user in instead of locking them out.
